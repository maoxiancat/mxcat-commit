# 安全提醒规范

- 出预览前和提交前对拟提交的内容进行检查，如有问题则进行提醒
- 仅进行提醒，继续出预览并创建对应条目，不影响放进拟提交 commit 里，不影响 commit 的提交/push

## 需要提醒的内容

- 新增内容中有疑似密钥、凭证或个人信息等涉及隐私/安全问题的内容。
- 已有内容中疑似密钥、凭证或个人信息等涉及隐私/安全问题的内容不进行提醒

## 预览里怎么写

- 位于全部条目之后、固定收尾之前，另起提醒块，每条路径一行。
- 提醒里只写路径。密钥、凭证和个人信息的内容留在文件里，不抄进预览。
- 没有此类路径时不加提醒块。
- 提醒单独成块，不写进某条的解释。
- 可以参考 [preview.md](preview.md) 中的示例
```text
提醒
- `.env` 看起来是密钥/凭证，且从未进过仓库。
- `contacts.csv` 看起来是个人信息，且从未进过仓库。
```
