# mxcat-changelog

## 安装

安装与验证见本技能目录 [README.md](README.md)。

## 约束范围

- 只有用户要求更新 CHANGELOG 时才进行更新，不再代码更新之后自行更新 CHANGELOG。
- 无特殊要求时，只约束本次新增 CHANGELOG，不改动 CHANGELOG 已有内容。
- 项目里已有明确 CHANGELOG 风格时，沿用项目已有风格更新 CHANGELOG。
- 根据规范中文件的要求，更新 CHANGELOG。
- 仅更新 CHANGELOG 文件，不进行其他额外操作

## 规范

| 规范类型 | 文件位置 |
| --- | --- |
| CHANGELOG 格式 | [references/format.md](references/format.md) |
| 新增内容确定 | [references/content.md](references/content.md) |
